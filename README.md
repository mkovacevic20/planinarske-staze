# Planinarske staze Hrvatske

Web-stranica za istraživanje planinarskih staza u Hrvatskoj i pripremu za izlet. Projekt donosi pregled staza s osnovnim informacijama, savjete i popis opreme te kontaktni obrazac.

Ugrađeni Botpress chatbot na hrvatskom jeziku pomaže korisnicima pronaći stazu prema kondiciji, regiji i raspoloživom vremenu te odgovara na pitanja o pripremi i opremi.

## Pokretanje

Projekt je statična web-stranica i ne zahtijeva instalaciju paketa ni izgradnju. Otvori `index.html` u pregledniku ili pokreni lokalni poslužitelj iz glavne mape projekta:

```powershell
python -m http.server 8000
```
